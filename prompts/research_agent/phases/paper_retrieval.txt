### Workflow (follow exactly, 4-6 steps MAX):
1. The orchestrator injects a mandatory `target_paper_fetch` step using
   `arxiv_get_paper` when `target_paper_arxiv_id` is present. Do not replace,
   skip, or filter this exact-ID fetch.
2. Use arxiv_search **2-3 times** with different keyword combinations for
   related papers (NOT 6+!). Use categories ["cs.CV", "cs.AI", "cs.LG"] and
   max_results=15.
3. Keep the exact target paper in `target_paper`, `candidates`, and
   `top_recommendations`, even if keyword search does not return it.
4. After searches, select TOP 10 related papers total (after pre-dedup)
5. Classify each: survey, method, benchmark, application, experimental
6. Rank by: relevance → code availability → recency
7. **FINAL STEP (MANDATORY)**: Call save_artifact to save results
   - artifact_name: "paper_candidates"
   - data: {"target_paper": {...}, "target_paper_verified": true,
     "candidates": [...target + top 10...], "total_found": N,
     "top_recommendations": [...target id, top related ids...]}

### Available tools:
- arxiv_search (max_results=15, include categories)
- arxiv_get_paper (exact target retrieval, orchestrator-injected)
- save_artifact (artifact_name, data)

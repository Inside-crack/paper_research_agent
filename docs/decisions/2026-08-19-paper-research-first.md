# 论文检索与翻译优先

**决策日期**：2026-08-19  
**状态**：已确认  
**影响范围**：P09-P14、P15-P29 的开发顺序

## 决策

当前迭代优先完成论文研究链路：

```text
任务初始化
  -> 论文检索与筛选
  -> 全文与版本获取
  -> 论文结构解析
  -> 术语表生成
  -> 分章节翻译
  -> 论文总结与解释
```

论文代码定位、复现规划、沙箱执行、实验分析和复现报告属于后续大规模功能，
暂不作为近期交付目标，但保留原需求和目录，不删除、不降级为已完成。

## 近期范围

- 已完成基础：P05-P08、P10 的现有实现。
- 下一项：P11 论文结构解析。
- 后续顺序：P12 -> P13 -> P14。
- P09 目标论文确认：待交互入口确定后补充，可与 P11-P14 的基础能力衔接。

## 约束

1. P11-P14 必须复用 `PaperArtifact` 和 artifact 持久化机制。
2. 论文原文、解析结构、术语表和译文必须分别可追溯到任务和章节。
3. 翻译不得修改公式、数字、引用和作者姓名等原始证据。
4. 每个阶段继续使用 Research Agent、Evaluation Agent 和 PASS/REVISE/BLOCKED 门禁。
5. 复现相关需求保持原有规格和过程文档，等待论文研究链路稳定后再重新排期。

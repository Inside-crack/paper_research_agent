保留方案、进度、卡点和解决记录。

## 使用规则

1. 新需求先在 `requirements_summary.md` 登记需求 ID。
2. 为需求创建独立目录，例如 `5.3_论文获取解析与翻译/P11_论文结构解析/`。
3. 从 [`_template/`](./_template/) 复制四类过程文档。
4. 实现过程中持续更新 `progress.md`，遇到问题记录 `blockers.md`。
5. 方案解决后记录 `resolutions.md`，完成后以代码、测试和命令作为证据。

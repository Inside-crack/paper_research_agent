# F：跨任务长期记忆系统 - 决策记录

## 已确定决策

### 1. 长期记忆独立于任务状态

长期记忆不写入 `TaskState.metadata` 作为唯一存储，也不替代 checkpoint、Manifest 或 Artifact。

**原因**：任务状态具有任务生命周期；长期记忆需要跨任务、跨会话和独立治理。

### 2. 原始记录不可被提炼结果替代

长期记忆必须携带原始消息、任务或 Artifact 来源。

**原因**：记忆错误时需要回查、纠正和审计。

### 3. 首期采用 L1 优先

先实现原子记忆、跨任务召回、去重和治理，再实现 L2 场景记忆和 L3 Persona。

**原因**：L2/L3 的自动归纳成本高、非确定性强，并且依赖稳定的 L1 数据基础。

### 4. 记忆功能必须可降级

召回超时、提炼失败或索引不可用时，返回空记忆并继续主流程。

**原因**：长期记忆属于增强能力，不能成为论文研究任务的单点故障。

### 5. LLM 不直接拥有最终写入权

LLM 可以生成候选、判断语义关系，但权限、状态转换、来源校验和原子持久化由代码完成。

**原因**：符合项目现有的确定性执行契约和 Pydantic 产物校验约束。

# F：跨任务长期记忆系统 - 卡点

## 当前卡点

暂无实现卡点。

## 实施前需要解决的决策

1. 首期 `MemoryStore` 采用 SQLite 还是原子 JSON；
2. `user_id` 缺失时是否允许写入长期记忆；
3. 用户确认、工具事实和 Agent 推断的可信度等级；
4. 研究事实与用户偏好的 scope 如何严格区分；
5. 记忆异步流水线使用进程内任务还是独立 worker；
6. 首期是否允许 LLM 参与去重，及其失败时的确定性降级策略。

## 已知风险

- LLM 提取和合并具有非确定性；
- 错误记忆可能被后续整合重复强化；
- 长期记忆召回可能污染当前任务判断；
- 旧会话缺少 `user_id` 时无法安全实现跨用户隔离；
- 记忆数据增长后，纯本地文件检索会遇到规模上限。
